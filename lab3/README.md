# Лабораторная работа 3 — Сериализация объектов (Binary)

## Задание
Иерархия классов, бинарная сериализация/десериализация, WPF-интерфейс.

## Предметная область
**Каталог медиа-контента** — библиотека различных типов медиа.

## Иерархия классов (7 классов)

```
MediaItem (абстрактный)
├── Book          — Книга
├── Magazine      — Журнал
├── EBook         — Электронная книга
├── Movie         — Фильм
├── MusicAlbum    — Музыкальный альбом
└── Audiobook     — Аудиокнига
```

## Реализация требований

### Сериализация
- **Формат**: Binary (вариант 2)
- Полиморфная сериализация через реестр типов (`TypeRegistry`)
- Без if-else/switch и рефлексии
- Добавление нового класса: новый файл модели + регистрация в `TypeBootstrap`

### UI (WPF)
1. **Редактирование** — общие свойства (Название, Год, Издатель) + специфичные для каждого типа через `DataTemplate`
2. **Добавление/удаление** — кнопки «Добавить» (диалог выбора типа), «Удалить»
3. **Сохранение/загрузка** — кнопки «Сохранить», «Загрузить» (диалог файла)

## Запуск

```bash
dotnet run
```

- `Models/` — иерархия MediaItem
- `Serialization/` — TypeRegistry, BinaryMediaSerializer, TypeBootstrap

- `Views/` — AddItemDialog
